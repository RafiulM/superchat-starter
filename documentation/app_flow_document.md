# Superchat Starter App Flow Document

## Onboarding and Sign-In/Sign-Up

When a brand new user visits the application, they land on a clean welcome page that explains the core features of the Everything-App AI platform. From here, they can choose to sign up or sign in. By clicking the Sign Up button, the user is taken to a page where they provide an email address and create a password. Once they submit this form, Better Auth processes the registration, sends a verification email, and displays a message prompting the user to confirm their address. After clicking the link in the email, the account becomes active. The user then returns to the application and signs in using their verified email and password. If at any point the user forgets their password, they can click the Forgot Password link on the sign-in page. This link leads to a recovery screen where they enter their email address, receive a reset link, and follow it to set a new password. After resetting, they return to the sign-in page to access their account. To sign out, the user simply clicks their avatar in the header and chooses Sign Out, which clears the session and returns them to the welcome page.

## Main Dashboard or Home Page

Upon successful sign-in, the user arrives at the main dashboard. The top of the screen features a header with the application logo on the left, a dark mode toggle on the right, and the user avatar in the corner. A vertical sidebar along the left edge lists the core features: Chat, Search, and Image Generation. The central area of the dashboard greets the user with a brief overview of their recent activity. It shows snapshots of the latest chat conversations, recent search queries, and recently generated images. The user can click any item in these previews to dive deeper into that feature. Navigation is intuitive: selecting Chat in the sidebar takes them to the chat interface, Search leads to the AI search console, and Image Generation opens the image prompt workspace.

## Detailed Feature Flows and Page Transitions

When the user clicks the Chat link in the sidebar, they are taken to the chat page at `/dashboard/chat`. This page displays a list of past conversations in a left panel. The user can click New Conversation at the top of that panel to start fresh. The main area shows the conversation thread. At the bottom of this area, a text input invites the user to type a message. After pressing Enter or clicking Send, the front end makes a request to `/api/chat`, where the Vercel AI SDK streams a response from the selected model. The user sees the AI reply appear in real time. Behind the scenes, each user message and AI reply is saved to the PostgreSQL database through Drizzle ORM, maintaining a complete history. The user can switch between available AI models using a dropdown, rename a conversation by clicking its title, or delete an entire thread from an overflow menu. They can also export a conversation transcript when needed.

Clicking Search in the sidebar leads to `/dashboard/search`. Here, the user finds a simple search bar at the top. They type a query and press Enter to send it to `/api/search`. The AI search endpoint returns relevant results in a scrollable list below, which the user can explore. Each result card shows a snippet of information and links to more details. The user can refine their query by editing the search term or starting a new search from scratch. Every search query is stored in the database, allowing the user to revisit past searches from the dashboard overview.

Selecting Image Generation directs the user to `/dashboard/image`. This page presents a prompt field, style options, and a Generate button. After entering a descriptive prompt and clicking Generate, the client calls `/api/image`. The AI SDK processes the request and returns one or more images. The page displays these images in a grid. The user can click an image to view it at full size, download it to their device, or save it to their personal gallery. All prompts and generated images are recorded in the database, so the user can see their creation history in the dashboard.

## Settings and Account Management

The user can manage their account by clicking their avatar in the header and choosing Settings. This opens the account management page where personal information such as display name and email address can be updated. The user may change their password by providing the current password and entering a new one. A set of preference toggles allows the user to switch between light and dark mode, enable or disable email notifications for new chat summaries, and configure other notification settings. If the application offers subscription tiers, the user can view their current plan, upgrade to a premium level, or cancel. Billing details and payment methods are displayed here, and the user can update their payment information. After saving any changes, a confirmation message appears. At any time, the user can return to the main dashboard by clicking the Back to Dashboard button at the top of the settings page.

## Error States and Alternate Paths

If the user enters invalid credentials on the sign-in page, an error message appears below the form fields prompting them to retry. During sign up, if the email is already in use or the password fails validation rules, the form highlights the issue and prevents submission. When requesting a password reset with an unrecognized email address, the system informs the user that the email was not found. If the user attempts to access a protected route without being signed in, they are redirected to the sign-in page with a notification explaining that authentication is required. While using chat, search, or image generation, network interruptions or server errors display an inline alert with a retry button. In case the AI service is temporarily unavailable, the user sees a friendly message that the feature is offline and will automatically retry once the service is restored. For database connectivity issues, a maintenance page replaces the dashboard, informing the user that the platform is undergoing routine maintenance.

## Conclusion and Overall App Journey

A user’s journey begins at the landing page where they sign up, verify their email, and sign in. They arrive on a unified dashboard that provides quick access to AI Chat, AI Search, and AI Image Generation. Within each feature, the user interacts seamlessly with the server via dedicated API routes, enjoys real-time AI responses, and sees all activity persist in their personal history. They can customize their experience through a comprehensive settings page, manage billing if they choose to subscribe, and recover access at any time through the password reset flow. Throughout the application, clear feedback, error handling, and simple navigation ensure that the user can focus on discovering and using AI features without confusion. From their very first interaction to everyday usage, the platform guides the user toward creating, searching, and generating content with a consistent and intuitive flow.
